# kharos brand kit

The kharos mark is an obol, the coin paid for the crossing, with a canoe over waves.

| File | Use |
|---|---|
| `mark.svg` | Mark on a transparent background, for light backgrounds |
| `mark-dark.svg` | Mark on a transparent background, for dark backgrounds |
| `icon.svg` | App icon with its rounded light background |
| `icon-dark.svg` | App icon with its rounded dark background |
| `icon-small.svg` | Simplified icon for 32 px and below (no dotted ring, heavier wave) |
| `wordmark.svg` | Mark and name, for light backgrounds |
| `wordmark-dark.svg` | Mark and name, for dark backgrounds |
| `wordmark-dark-card.svg` | Mark and name on a rounded dark red card (`#3F0F16`), used by the README in dark mode |
| `png/icon-{1024,512,256,64}.png` | Raster exports of `icon.svg` |
| `png/icon-{32,16}.png` | Raster exports of `icon-small.svg` |
| `png/avatar.png` | Square 1024 px avatar with a full-bleed background, for GitHub and other services that crop their own shape |
| `favicon.ico` | 16, 32 and 48 px favicon |
| `social-preview.png` | 1280 x 640 repository social preview |

The name in the wordmarks is outlined from Iowan Old Style Bold, so the SVGs need no font.

## Palette

| Name | Hex | Role |
|---|---|---|
| Sangue de boi | `#3F0F16` | Waves on light; dark background |
| Vinho | `#7A1F2B` | Coin rings and name on light |
| Bronze | `#B07A3A` | Palette reference; the canoe uses `#8E5A22` on light and `#D9A25E` on dark for contrast |
| Rosa seco | `#E8C4BE` | Waves on dark |
| Osso | `#F7F1EA` | Light background; rings and name on dark |
